## vite.config.js
- файл контролируем как vite ведет себя,
- необходимо перед его изменением остановить vite server (командой Ctrl+C)
- лежит в корне vue-проекта

Что из vite.config.js можно извлечь:

```
import { fileURLToPath, URL } from 'node:url'

import { defineConfig } from 'vite'
import vue from '@vitejs/plugin-vue'
import vueDevTools from 'vite-plugin-vue-devtools'
 

// https://vite.dev/config/
export default defineConfig({
  plugins: [ // **установленные плагины (можем отключить их, просто закомментировав)**
    vue(),
    vueDevTools(),
  ],
  resolve: {
    alias: {
      '@': fileURLToPath(new URL('./src', import.meta.url))
    },
  },
})
```

## App.vue

- находится в папке src - директории, в которой большая часть разработки будет происходить
- это то, что зовется Single File Component (или SFC) - вся логика, разметка и стили компонента, содержатся в подобном файле.
- Состоит из следующих секций:
```
<script setup> //  скрипты
</script>

<template> // разметка
</template>

<style scoped> // стили
</style>
```
